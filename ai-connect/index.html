The connection token is a remote-control key. Anyone who has it can make the agent run commands on your computer. Paste it only into pages you trust.

Only for GitHub Enterprise with its own domain. Enterprise Cloud on github.com (SSO orgs) leaves this empty. Changing it re-points the whole local host.

How do I get a GitHub token? 
gh auth login
gh auth token

If the host rejects it, add the Copilot scopes with gh auth refresh -s read:user,user:email. With SSO, authorize the org when gh asks.

Personal access tokens don't work here, classic (ghp_…) or fine-grained (github_pat_…). GitHub's Copilot service accepts them only from the official Copilot CLI, and the VS Code agent host is a different client. Use gh auth token.

The host lets the agent read and write files in this folder without asking, and runs commands it considers safe. It asks before anything else. Use a dedicated folder.
